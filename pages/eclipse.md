INCEpTION has been proposed as a project of the [Eclipse Foundation](https://www.eclipse.org).
Becoming an Eclipse project would give INCEpTION a vendor-neutral home with open governance, making
it easier for people and organizations beyond the current team to contribute and to rely on the
project in the long term.

While the proposal is under review, the Eclipse Foundation looks at whether the project has an
active, real-world community. **This is where you can help:** leave a comment on the proposal and
tell them how you use INCEpTION.

### How to comment

1. Create a free [Eclipse account](https://accounts.eclipse.org/user/register), if you do not have
   one yet.
2. Log in to your account.
3. Open the [proposal page](https://projects.eclipse.org/proposals/eclipse-inception).
4. Scroll to the bottom of the page. When you are logged in, you will find a comment form there.

**Please note:** comments are moderated, so yours will not appear right away. There is no need to
post it a second time.

### What could I write?

The goal is to show the Eclipse Foundation that INCEpTION has an active, real-world user base. A
short comment is perfectly fine. You can simply express your interest in the project as a user,
suggest improvements to the proposal itself, or highlight specific ways you rely on the software:

* **Personal use:** If you use INCEpTION, and perhaps chose it over other tools for specific
  reasons, say so.
* **Institutional use:** If you run an INCEpTION server for a research group, institution,
  community, or country, mentioning that is a huge plus.
* **Scientific publications:** If you used INCEpTION in the preparation of a scientific
  publication, it is worth a note, in particular if you plan to do so again.
* **Funding and grants:** If you wrote into a funding proposal that your research project uses
  INCEpTION, that strongly demonstrates the project's value.
* **Teaching and education:** Let us know if you use INCEpTION to teach students, or feature it in
  tutorials and workshops for your community.
* **Future contributions:** Note if you have contributed to INCEpTION in the past, or could imagine
  doing so in the future, especially if becoming an Eclipse project would make those contributions
  easier.

### Be listed as an interested party

You can also ask to be named as an interested party in the proposal, in particular if you speak
for a group or institution with a vested interest in INCEpTION. Just say so in your comment, or
[contact us]({{ site.url }}/contact/).

### Prefer not to create an account?

You can also let us know on the [users mailing list](https://groups.google.com/d/forum/inception-users).
Thank you for your support!
